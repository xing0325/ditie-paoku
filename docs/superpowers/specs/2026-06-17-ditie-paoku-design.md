# 倒反天罡版地铁跑酷 — 设计 Spec **v2**

> 工作标题:**《没有目的地》**(暂定;备选《它不会等你》《下一趟照常发车》)
> 日期:2026-06-17 · 状态:待用户审阅(v2 已并入"交互层倒反复刻 + 撞击反馈 + 尸堆")

---

## 1. 一句话

你不是在地铁里跑酷的人,**你就是那辆地铁**——在三条轨道上转弯穿梭,碾过被困在轨道上的人,没有目的地,永不停车。一个把"电车难题"倒过来玩、并在**交互层逐项复刻**原版《地铁跑酷》的 3D 跑酷。

## 2. 核心反转

- **原版**:人在地铁间跑酷,躲开列车。「人」是主角,「车」是威胁。
- **本作**:角色互换。「**地铁在跑酷**」——列车是主角,人类成了被碾的环境物。
- **同构发现**:竖屏跑酷"三道切换" ≡ 电车难题"切换轨道"。本作把这层同构显性化为核心机制。
- **复刻原则**:原版的**手势词汇 1:1 全保留**(这就是"交互层像素级复刻"),只把语义倒过来——跑者→地铁,人类→环境物。

## 3. 调性(已锁)

**B + C:冷面荒诞**。底层哲理(B),外壳黑色幽默(C),但幽默是**冷的、奇古尔式、平到发冷的**,不是卡通搞笑。

- 参考:**《The Wire》**(制度照常运转,个体被碾,齿轮不停)、**《No Country for Old Men》**(暴力非戏剧化、突然;世界不为任何人停顿)。
- 定调句:**"世界只是运作,它不会等你。"**
- 荒诞与冷的分工:**物理上荒诞**(一台地铁面无表情地"嘿"一下跳过抛锚车),**叙述上冷**(平淡旁白 + 漠然 HUD)。两者叠加 = 冷面荒诞的巅峰。

## 4. 主题 / 意义(已锁:F2)

不评判、不煽情。游戏只是**让机器运转**,然后让你意识到:

- 你以为你在"躲",但**没有干净的选项**;不选,本身也是一种选。
- 真正令人不安的不是杀戮,是这一切的**无意义与不可停止**——而你居然还在玩。
- 反转的意义:哲学课的电车难题里"你"是有时间纠结的道德主体;这里**世界才是主体,它不等你**,你只是偶尔能拨一下方向盘的乘客。

## 5. 核心玩法循环(已锁)

### 5.1 主循环(借原版手感)
- 列车**永远向前、永不停、不能主动刹车**;玩家用**全套原版手势**操作(见 §6)。
- 速度**不动声色地缓增**(非街机狂飙),配合冷感。
- 轨道上不断出现人。

### 5.2 设计核心:游戏从不明说"该躲还是该压"(已锁,用户确认)
- **没有任何提示叫你躲人或压人。** 人像原版的金币串一样**成串铺在轨道上诱你走线**;碾过去有**强烈爽快的撞击反馈**(见 §7),计数上涨、尸体堆叠。
- 手感**诱你去压**,冷框架(平 HUD / 漠然旁白 / 永不消失的尸堆)**慢慢把那份爽变得不安**——笑着笑着笑不出来。这是 F1(共犯)+ F2(漠然)的钩子。

### 5.3 关键支柱:碾人**永不导致失败**(已锁)
- 撞人**不结束游戏**,只让**碾压计数 +1** + 触发反馈 + 尸体堆积。世界不为尸体惩罚机器。
- **唯一的失败来自"会让机器停下的硬障碍"**(止冲挡/抛锚车/集装箱):撞上 = **脱轨 = 本局结束**。
- 这条把"道德选择(人)"与"失败状态(障碍)"**彻底分开**:系统从不为它碾过的人付代价,只为"自身被中断"付代价。

### 5.4 招牌机制:「它不会等你」(已锁)
- **岔路口不暂停、不慢放**。周期性出现**"被迫二选一"高潮**:三车道**全有人、没有空轨**(如 1/3/5,带身份标签),必须选一条压过去。
- 玩家**不操作 → 列车保持当前车道**(惯性即默认,世界替你选了,且毫不在意)。复用同一套切道操作,不引入新按键。

## 6. 交互层倒反复刻(v2 核心新增)

### 6.1 手势(原版保留,语义倒反)— ✅ 拥抱荒诞跳跃(用户确认)

| 手势 | 原版 | 倒反天罡版 | MVP |
|---|---|---|---|
| **← →** | 跑者切道躲车 | 地铁**切轨** | ✅ |
| **↑ 跳** | 跳过障碍 / 跳上车顶跑 | 地铁**跳起**越过会脱轨的硬障碍;道具下可**跳上车顶/人墙**在上面碾 | ✅基础跳 / 上顶后续 |
| **↓ 滚** | 从低障下铲过 | 地铁**下压**钻过低净空(塌桥/天桥/限高栏) | ✅ |
| **空中再 ↓** | 急速下落 | **砸下**:落地范围冲击,周围人齐飞(连招) | 后续 |
| **空中 ← →** | 空中变道 | 腾空中仍可变轨 | ✅ |
| **双击** | 放滑板,免一次撞 | 放**备用转向架/缓冲器**,免一次脱轨 | 后续 |

### 6.2 收集物倒反

| 原版 | 倒反天罡版 | MVP |
|---|---|---|
| **金币串** | **人/人群**:碾过=收集,计数+尸堆,诱你主动压 | ✅ |
| 钥匙 | "下一趟"代币:换新涂装车 / 复活 | 后续 |
| 神秘盒 | 轨道上的箱子:撞开掉道具/特殊受害者 | 后续 |
| 字母拼 SUBWAY | 拼冷词(乘客/效率/无人认领),凑齐给漠然奖励 | 后续 |

### 6.3 道具倒反(全部冷处理)

| 原版 | 倒反天罡版 | MVP |
|---|---|---|
| 金币磁铁 | **人群磁铁**:把邻轨的人吸到你这轨一起碾 | 后续 |
| 2X 倍数 | **效率 ×2**:碾压计数翻倍,HUD 冷标"产能 ×2" | 后续 |
| 喷气背包 | **脱轨升空**短暂飞行,碾"天台人群",无敌 | 后续 |
| 强力跳鞋 | **强力悬挂**:跳更高,上车顶/人墙 | 后续 |
| 弹簧高跷 Pogo | **液压弹跳**:连续弹跳,每次落地砸一片 | 后续 |
| Mega Headstart | **提前发车**:开局直接高速冲一段 | 后续 |

### 6.4 障碍 & 追逐者倒反

| 原版 | 倒反天罡版 | MVP |
|---|---|---|
| 列车(挡路;有的带坡可上顶) | **硬结构**(止冲挡/抛锚车/集装箱)= **脱轨失败**源;带坡的可冲上顶碾一段 | ✅硬障碍 / 上顶后续 |
| 4 种栏 | 限高(↓钻)/ 低障(↑跳)/ 整轨封死(必变轨) | ✅ |
| 柱子 / 隧道 / 坡道 | 轨间柱(走边轨)、隧道天桥(视野压缩)、坡(起跳→落地连撞) | 后续 |
| **督察+狗追你,撞了抓你** | **追不上的"监察者"**(NCFOM 老警长 / Wire 好警察):跟在后面收尸,从不评判也从不放弃,但机器太快追不上。**你脱轨停下他才追到 = 本局结束**。"你没了,系统还在,他还在收拾" | 后续(MVP 用文字卡) |

## 7. 撞击反馈 + 尸堆系统(v2 核心新增,用户点名)

### 7.1 撞击 juice(MVP 做满)
- **Hit-stop**:每次有效撞击冻帧 30–60ms(撞人群更久)——重量感的灵魂。
- **镜头震**(按撞击量缩放)+ **布娃娃抛飞**(低面 ragdoll,前/外向冲量 + 旋转)。
- 碾过密集人群 → 短暂**慢动作**,让惨状被看见。
- **音效**:平、闷的"咚/嘎吱",冷,不卡通尖叫。
- **粒子**:风格化低面碎块。

### 7.2 血腥度:都做 + 设置切换(用户确认)
- **默认:风格化红块**(和 toon 一致,不 edgelord)。
- **设置里可切"写实"模式**(更真实的血/反应)。
- → MVP 需要一个**极简设置入口**(就一个血腥度开关,不是完整设置系统)。

### 7.3 尸堆
- 尸体**不消失**,堆积在轨道 + **车头逐渐长出一坨尸体"排障器"**(随局数视觉升级,黑色幽默 + 压迫感)。
- 计数照 tick,但 HUD **视觉保持平**——冷框架不动。
- **MVP:纯视觉升级**(用户采纳推荐)。
- **后续(用户明确"别忘记"):尸堆影响操控 / 变障碍**——坟包颠簸、堆积拖慢、可再撞的障碍物化。

## 8. 收场 / 失败(已锁:B)

- **无限跑 + 撞硬障碍脱轨失败**。
- 死亡画面**冷处理**:**"这趟到此为止。下一趟照常发车。"** + 本局距离 / 碾压数。
- (后续)镜头里**另一辆车照常驶过** + 监察者追到。MVP 先用文字卡。
- 点击 / 按键重开。

## 9. 计分 · HUD · 旁白

- **不叫"得分",叫"距离"**:`距离 1,284 m`。
- **碾压计数**平淡:`碾过 7`,无庆祝。
- **旁白**稀疏、平、偶发:"前方依然没有目的地。""它不会停,也不会等你。""第 100 个。系统未记录姓名。"
- HUD 极简:顶部距离+碾压数,底部偶发旁白字幕,低饱和。

## 10. 美术方向(已锁:真 3D / 三渲二)

- 真 3D,车后跟随镜头(原版本就是这种 3D,走 3D 更还原)。
- **低多边形 + 卡通着色(`MeshToonMaterial` 阶梯渐变)+ 描边**,即"三渲二"。
- **地铁 = 没表情的钝铁块**(深色挡风玻璃 + 车灯,奇古尔式)。
- 调色板:水泥灰 / 低饱和,列车一点暗赭暖意;雾化做冷纵深。
- 血:默认风格化红块;写实模式可切(§7.2)。不要霓虹、不要弹跳庆祝特效。

## 11. 平台 / 操作

- **Web(HTML5 + WebGL)**,单页,浏览器原生;GitHub Pages / Railway 静态秒部署。
- **响应式**,竖/横屏皆可(相机自适应);主开发目标桌面浏览器,移动端触控支持。
- 操作:**桌面键盘** ←→/AD 切轨、↑/W 跳、↓/S 钻;**移动端**左右/上/下**滑动**。

## 12. 技术架构(已锁:① Three.js)

- **Three.js(ES module + importmap,CDN,零构建)**,单页 + 模块化 JS。
- 渲染:`WebGLRenderer` + 车后 `PerspectiveCamera` + `Fog` + 灯光 + `MeshToonMaterial` + 描边。
- 无限滚动 + 尸体/障碍用**对象池**回收。碰撞用**车道 + z 区间**判定,无需物理引擎(布娃娃用简单冲量积分即可)。
- 在 Intel 核显上低面 + 简单着色很轻。

### 12.1 模块划分

| 模块 | 职责 |
|---|---|
| `main.js` | 启动、主循环、状态机驱动 |
| `scene.js` | 场景/相机/渲染器/灯光/雾、toon 材质工厂、描边工具 |
| `track.js` | 地面/车道线/轨枕,滚动 + 回收 |
| `train.js` | 玩家列车:车道 + **跳/钻垂直状态机** + 摇摆 + 车头尸堆 |
| `input.js` | 键盘 + 触摸滑动 → ←→↑↓ 意图(含空中变道) |
| `spawner.js` | 按难度生成人群 / 硬障碍 / 限高低障 / 被迫二选一墙 |
| `victims.js` | 受害者类型/标签库、低面人物 |
| `collision.js` | 区分:人(收集+juice,不致败)/ 硬障碍(脱轨)/ 栏(跳钻变轨清除);碾压计数 |
| `forcedChoice.js` | "三道全堵"高潮 + "不会等你"默认逻辑 |
| `juice.js` | hit-stop / 镜头震 / 慢动作 / 撞击连招 |
| `corpses.js` | 布娃娃抛飞 + 尸体持久化 + 堆积(轨道 + 车头) |
| `hud.js` | 距离 / 碾压数 / 旁白字幕(DOM 叠层) |
| `narrator.js` | 稀疏冷面旁白库 + 触发 |
| `settings.js` | 极简设置:血腥度开关(风格化/写实) |
| `gameState.js` | 状态机:`running / forcedChoice / dying / dead` |

## 13. 3D 素材管线

- **MVP**:基本几何体(盒子=地铁/障碍、胶囊+球=小人)+ toon + 描边,立刻能玩。
- **之后**:精致低面模型走 **Blender(已接 Blender MCP:文本生成 3D / Polyhaven / Sketchfab)**,或交 **Codex(image-2 出概念图再建模)**,以 `.glb` 替换占位,接口不变。

## 14. MVP 范围(v1,聚焦单一实现计划)

**做(IN):**
- 3D 三车道无限跑(toon + 描边),车后镜头。
- 列车永不停;手势 **←→ 切轨 / ↑ 跳 / ↓ 钻 / 空中变道**(拥抱荒诞)。
- **人即金币**:成串人群,碾过=收集;游戏不提示躲或压。
- **撞击 juice 做满**:hit-stop、镜头震、布娃娃抛飞、人群慢动作、闷响音效、风格化血粒子。
- **血腥度开关**(风格化/写实)的极简设置入口。
- **尸堆视觉升级**(轨道 + 车头持久堆积)。
- 碰撞三分类:碾人(计数,不败)/ 硬障碍(脱轨败)/ 限高低障封轨(跳钻变轨清除)。
- **一种**"被迫二选一"高潮(三道全堵 + 不操作=保持当前道)。
- HUD 距离 + 碾压数 + **稀疏旁白**;失败文字卡"这趟到此为止。下一趟照常发车。" + 重开。
- 桌面键盘 + 移动滑动;2–3 种日常受害者类型。

**不做(OUT,后续 —— 含用户明确"别忘记"项):**
- **尸堆影响操控 / 变障碍物(坟包颠簸/拖慢/可再撞)← 用户点名后续必做。**
- 跳上车顶/人墙在上面跑;空中"砸下"范围连招;双击放备用转向架免脱轨。
- 道具:人群磁铁 / 效率×2 / 脱轨升空 / 强力悬挂 / 液压弹跳 / 提前发车。
- 收集物:"下一趟"代币(钥匙)/ 神秘盒 / 字母拼冷词。
- **追不上的监察者** + 死亡过场(另一辆车驶过)。
- 柱子 / 隧道天桥 / 坡道;更多受害者类型;移动端精细适配。
- 音乐/音效打磨;Blender 精模替换;菜单/存档/排行榜。

## 15. 待定 / 开放问题

1. **正式游戏名**(暂定《没有目的地》)。
2. 首发主推**竖屏还是横屏**(响应式两可,调优期定)。
3. 旁白文案量与触发密度(实现后手感调)。
4. 失败硬障碍的视觉化(止冲挡/抛锚车/集装箱),MVP 先一种盒子占位。
